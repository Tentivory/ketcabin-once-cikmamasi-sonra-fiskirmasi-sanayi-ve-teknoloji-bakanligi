# ketcabin-once-cikmamasi-sonra-fiskirmasi-sanayi-ve-teknoloji-bakanligi
Ketçabın önce hiç çıkmamasını sonra masayı boyamasını resmi sanayi kazası, milli viskozite egemenliği ihlali ve üretim protokolü sapması sayan; kapağı vana, şişeyi tesis, 'biraz sallarım gelir' cümlesini Ar-Ge bülteni ilan eden Bakanlık. Gerçekten çalışır. Ketçaplar artık fabrikadır.
