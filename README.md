## Bu proje neden vardır?

Çünkü insanlık yüzlerce yıldır aynı şişeyi sallamaktadır ve hâlâ şaşırmaktadır. Bilim bunu açıklayamadı. Bürokrasi açıkladı: **protokol sapması**.

Bu depo:

1. Olayı ciddiye alır.
2. Olayı fazla ciddiye alır.
3. Olayı öyle ciddiye alır ki gülersiniz.
4. Sonra damga basar.

## Kuruluş

```bash
git clone https://github.com/Tentivory/ketcabin-once-cikmamasi-sonra-fiskirmasi-sanayi-ve-teknoloji-bakanligi.git
cd ketcabin-once-cikmamasi-sonra-fiskirmasi-sanayi-ve-teknoloji-bakanligi
python3 bakanlik.py
```

Parametreli resmi başvuru:

```bash
python3 bakanlik.py --salla 12 --sicaklik 24.5 --kapak 0.5 --sabir 2
```

- `--salla` şişeyi kaç kez salladığınız  
- `--sicaklik` şişe sıcaklığı (°C)  
- `--kapak` kapağın kaç tur açıldığı  
- `--sabir` 0–10 arası vatandaş sabrı

Yazılım çıktı olarak resmi durum raporu üretir. Gerçekten çalışır. Ketçap çıkmasa da rapor çıkar.
